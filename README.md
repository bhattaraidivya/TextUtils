# TextUtils

A simple React-based text utility app that allows users to analyze and manipulate text quickly — including features like word count, character count, and theme switching between light and dark modes.

## 🔧 Features

- Toggle between Light and Dark Mode
- Count words and characters
- Responsive UI with Bootstrap
- React Router for navigation
- Alerts for user feedback

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

```bash
git clone https://github.com/your-username/TextUtils.git
cd TextUtils
npm install
npm start
